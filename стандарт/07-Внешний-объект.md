# Внешний объект

\# Объект, чьё поведение спецификация не описывает: почтовый сервер, платёжный шлюз, журнал. Его документ записывает только заголовки методов, которые вызывает код, и перечисления их параметров и ответов.

## Элементы документа внешнего объекта

\# Документ внешнего объекта делится на разделы и подразделы ([Оформление: Элементы документа](01-Оформление.md#Элементы%20документа)). В колонке «Таблица» — шапка единственной таблицы элемента.

| Раздел | Что содержит | Таблица | Подразделы | Обязателен |
|---|---|---|---|---|
| Методы | Методы, которые вызывает код; только заголовки | Нет | Метод | Да |
| Типы и перечисления | Перечисления параметров и ответов | Нет | Перечисление | Если есть |
| Техническое соответствие | Вид и модуль ([Техническое соответствие](#Техническое%20соответствие)) | `Свойство \| Значение` | Нет | Да |

| Подраздел | Заголовок | Что содержит | Таблица | Пункты |
|---|---|---|---|---|
| Метод | Заголовок метода: `Отправить(Адрес: Строка(100), Текст: Строка(200))` ([Методы: Заголовок метода](04-Методы.md#Заголовок%20метода)) | Имя, параметры и, если есть, тип ответа | Нет | Нет |
| Перечисление | Имя типа: `ВажностьПисьма` ([Типы: Определение типа](03-Типы.md#Определение%20типа)) | Значения типа | `Имя \| Описание`, за ними колонки свойств | Нет |

| Правило | Как выполнять | Проверка |
|---|---|---|
| ЕстьМетод | В «Методах» есть хотя бы один метод; у метода только заголовок, пунктов в документе нет | Генератор |
| ПапкаИнтеграций | Документ вида `Внешний объект` лежит в папке `Интеграции/` спецификации или в её вложенной папке; других документов в ней нет | Генератор |
| МодульИнтеграции | Модуль внешнего объекта лежит в папке `интеграции/` кода: `код/интеграции/почта.py` | Нет |
| ПравилаОбъекта | Из [Документа объекта](02-Документ-объекта.md) действуют `ПорядокРазделов`, `Подразделы` и `ОднаТаблица` — по таблицам элементов этой части, — а также `ИмяОбъекта`, `ОдинИсточник`, `КодВТехническомРазделе` и `ИменаВКоде`. Из [Методов](04-Методы.md) действует только `ЗаголовокМетода`. Перечисление определяется по правилам [Типы: Определение типа](03-Типы.md#Определение%20типа). Вызов метода внешнего объекта в действиях другого объекта записывается по «Методам», как любой вызов | По этим правилам |
| БезТестов | По документу внешнего объекта генератор тестов не порождает: ни теста реализации, ни тестов перечислений. Внешний объект участвует только в тестах других объектов — как регистратор ([Вызов внешнего объекта](#Вызов%20внешнего%20объекта)) | Нет |

## Техническое соответствие

| Правило | Как выполнять | Проверка |
|---|---|---|
| Реализация | Таблица свойств (`Свойство`, `Значение`), каждое свойство — одной строкой: `Вид` — `Внешний объект` ([Оформление: Элементы документа](01-Оформление.md#Элементы%20документа)); `Модуль` — файл кода с классом, через который код вызывает внешний объект. Других свойств нет | Генератор |

## Вызов внешнего объекта

| Правило | Как выполнять | Проверка |
|---|---|---|
| ВызовВнешнего | Объект обращается к внешнему через реквизит типа `Ссылка."Почта"`: действие `Почта.Отправить(Адрес, «текст»)`. В тесте внешний объект заменяется регистратором, и проверяется, что вызовы были ровно с такими параметрами, в таком порядке | Тесты |
