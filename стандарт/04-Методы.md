# Методы

\# Метод — поведение объекта. Он записывается таблицей решений, если выбирается один исход, или таблицей шагов, если выполняется последовательность действий. Внутренний алгоритм не описывается: только то, что видно снаружи.

## Заголовок метода

| Правило | Как выполнять | Тест |
|---|---|---|
| ЗаголовокМетода | Заголовок раздела метода — имя и параметры в скобках, скобки есть и без параметров: `Оплатить()`, `Отменить(Причина)`. Так метод не совпадает по заголовку с одноимённым типом | `test_формат_метода` |

## Таблица решений

| Правило        | Как выполнять                                                                                              | Тест                 |
| -------------- | ---------------------------------------------------------------------------------------------------------- | -------------------- |
| КолонкиРешений | `Правило`, `Условие`, `Эффект`, `Итог`, `Тест`                                                             | `test_формат_метода` |
| ПорядокРешений | Строки проверяются сверху вниз; выполняется первая с истинным условием                                     | `test_формат_метода` |
| ИтогВсегда     | Последняя строка метода — без условия (`—`), чтобы итог был всегда                                         | `test_формат_метода` |
| Итог           | Итог — значение на языке выражений, `Ошибка «текст»` или `—`, если метод ничего не возвращает             | `test_выражения`     |

## Таблица шагов

| Правило | Как выполнять | Тест |
|---|---|---|
| КолонкиШагов | `Правило`, `Шаг`, `Условие`, `Эффект`, `При сбое`, `Тест` | `test_формат_метода` |
| ПорядокШагов | Шаги выполняются по порядку номеров; шаг с ложным условием пропускается | `test_формат_метода` |
| ПриСбое | Для каждого шага указано, что остаётся неизменным или что происходит при сбое; `—`, если сбой не важен | `test_формат_метода` |

## Специальные методы

\# Методы, которые вызывает сама программа в определённый момент.

| Имя | Когда вызывает программа | Для чего |
|---|---|---|
| ПриСоздании() | Объект создан, до первого сохранения | Начальные значения сложнее, чем `= значение` в типе |
| ПередУдалением() | Перед удалением объекта | Отменить связанную работу или запретить удаление (`Ошибка «текст»`) |
| ПриОбновлении() | Для каждого хранимого объекта при первом запуске новой версии, до `ПриЗапуске()` | Перенос данных при переименовании, удалении или смене типа реквизита |
| ПриЗапуске() | Для каждого хранимого объекта при запуске программы, до первого запроса | Привести объект в порядок после перезапуска |

| Правило | Как выполнять | Тест |
|---|---|---|
| СпециальныйМетод | Метод с именем из таблицы выше вызывает программа в указанный момент; другие методы его не вызывают, параметров у него нет. Описывается в разделе «Методы» таблицей решений или шагов, как обычный метод | `test_формат_метода` |
| ИменаСпециальных | Имя метода на «При» или «Перед» — только из таблицы выше | `test_формат_метода` |

## Язык выражений

\# Один язык для условий, эффектов и итогов.

| Обозначение | Смысл |
|---|---|
| `Реквизит` | Значение своего реквизита: `Статус` |
| `Реквизит.Реквизит` | Реквизит через ссылку или вложенный тип: `Покупатель.Баллы`; через пустую ссылку — `null` |
| `Параметр` | Параметр метода по имени из заголовка: `Причина` в `Отменить(Причина)`. Имя параметра не совпадает с именем реквизита |
| `=`, `≠`, `<`, `>`, `∈`, `null`, `и`, `или`, `не` | Сравнения и логика |
| `+`, `-`, `*`, `/` | Арифметика |
| `Реквизит := значение` | Эффект: присвоить значение |
| `;` | Разделитель нескольких эффектов |
| `Метод(параметры)` | Вызов другого метода того же объекта |
| `{Реквизит: значение}` | Значение вложенного типа или объекта |
| `[]` | Пустой список; `Список + элемент` и `Список + Список` добавляют элементы |
| `Последние(Список, N)` | Последние N элементов списка |
| `Отбор(Список, условие)` | Элементы списка, для которых условие истинно; в условии — реквизиты элемента |
| `—` | Нет условия, эффекта или итога |
| Значение перечисления | Имя из таблицы перечисления: `Статус = Оплачен` |
| `Сейчас` | Текущие дата и время |
| `Ошибка «текст»` | Итог: отказ с текстом для пользователя |

| Правило   | Как выполнять                                                                                                    | Тест             |
| --------- | ---------------------------------------------------------------------------------------------------------------- | ---------------- |
| Выражение | Каждая ячейка условий, эффектов и итогов записана обозначениями таблицы выше; неизвестный реквизит, параметр или значение — ошибка | `test_выражения` |

## Пример

\# Метод «Оплатить» объекта «Заказ».

| Правило | Условие | Эффект | Итог | Тест |
|---|---|---|---|---|
| ОплатаОплаченного | Статус = Оплачен | — | Ошибка «Заказ уже оплачен» | `test_оплата_оплаченного_заказа` |
| Оплата | — | Статус := Оплачен; ДатаОплаты := Сейчас | — | `test_оплата_заказа` |
