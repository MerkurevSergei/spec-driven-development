# Изменение спецификации

\# Статусов в спецификации нет. Состояние работы показывает парсер: зелёный — спецификация, код и тесты совпадают; красный — работа не закончена. Идеи на будущее живут вне спецификации, в заметках.

## Предлагаемые изменения

| Правило | Как выполнять | Тест |
|---|---|---|
| Место | Предлагаемое изменение — работа, которую берут сразу: файл `<тема>.md` в папке `предлагаемые-изменения/` | `test_формат_изменения` |
| Строки | Раздел на каждый изменяемый раздел целевого документа; заголовок раздела — ссылка на него: `[Заказ: Оплатить()](../Заказ.md#Оплатить())`. Таблица в формате целевого раздела с первой колонкой `Изменение`: `Добавить`, `Изменить` или `Удалить`; вторая — имя правила, в таблице данных — `Имя`. `Изменить` содержит новую редакцию строки целиком | `test_формат_изменения` |
| ЗаменаЦеликом | Если документ заменяется целиком — файл `<имя документа>.предлагаемое-изменение.md` рядом с ним, в формате целевого документа, без колонки `Изменение`. Если изменение переименовывает документ, сначала документ переименовывается отдельным коммитом вместе со всеми входящими ссылками, без правки содержимого | `test_формат_изменения` |
| Цели | Для `Изменить` и `Удалить` правило есть в целевом документе, для `Добавить` — ещё нет | `test_формат_изменения` |
| ТестыВИзменении | Колонка `Тест` — тесты, которые нужно написать, или `ТребуетсяТест`; их существование не проверяется | `test_формат_изменения` |
| Перенос | Строки переносятся в целевые документы, перенесённые строки удаляются из изменения, пустое изменение удаляется. Строка, которая есть и в изменении, и в цели в одной редакции, — ошибка | `test_формат_изменения` |

## Пример предлагаемого изменения

\# Файл `предлагаемые-изменения/Баллы-за-оплату.md`, раздел для метода «Оплатить» документа «Заказ».

| Изменить | Оплата | — | Статус := Оплачен; ДатаОплаты := Сейчас; Покупатель.Баллы := Покупатель.Баллы + Сумма / 100 | — | `test_оплата_начисляет_баллы` |
