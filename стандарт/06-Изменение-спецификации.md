# Изменение спецификации

\# Статусов в спецификации нет. Состояние работы показывает CI: зелёный — спецификация и код совпадают; красный — работа не закончена. Идеи на будущее живут вне спецификации, в заметках.

## Предлагаемые изменения

| Правило | Как выполнять | Проверка |
|---|---|---|
| Место | Предлагаемое изменение — работа, которую берут сразу: файл `<тема>.md` в папке `предлагаемые-изменения/` | Нет |
| Строки | Раздел на каждый изменяемый раздел или подраздел целевого документа; заголовок — ссылка на него: `[Заказ: Оплатить()](../Заказ.md#Оплатить())`. Таблица в формате целевого раздела с первой колонкой `Изменение`: `Добавить`, `Изменить` или `Удалить`; вторая — имя правила, в таблице данных — `Имя`. `Изменить` содержит новую редакцию строки целиком | Нет |
| ЗаменаЦеликом | Если документ заменяется целиком — файл `<имя документа>.предлагаемое-изменение.md` рядом с ним, в формате целевого документа, без колонки `Изменение`. Если изменение переименовывает документ, сначала документ переименовывается отдельным коммитом вместе со всеми входящими ссылками, без правки содержимого | Нет |
| Цели | Для `Изменить` и `Удалить` правило есть в целевом документе, для `Добавить` — ещё нет | Нет |
| Перенос | Строки переносятся в целевые документы, перенесённые строки удаляются из изменения, пустое изменение удаляется. Строка, которая есть и в изменении, и в цели в одной редакции, — ошибка | Нет |
| НеЧитаетсяГенератором | Папку `предлагаемые-изменения/` генератор пропускает ([ФайлыСпецификации](05-Тесты-по-спецификации.md#Файлы%20спецификации)): тесты порождаются только по действующим документам | Генератор |

## Пример предлагаемого изменения

\# Файл `предлагаемые-изменения/Баллы-за-оплату.md`, раздел для метода «Оплатить» документа «Заказ».

### [Заказ: Оплатить()](../Заказ.md#Оплатить())

| Изменение | Правило | Условие | Действия | Ответ |
|---|---|---|---|---|
| Изменить | Оплата | — | Статус := Оплачен; ДатаОплаты := Сейчас; Покупатель.Баллы := Покупатель.Баллы + Сумма / 100 | — |
