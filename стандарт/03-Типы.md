# Типы

\# У каждого реквизита есть тип. Объект спецификации — тоже тип: документ объекта определяет его, а другие документы ссылаются на него.

## Виды типов

| Вид | Как записывается | Где определяется |
|---|---|---|
| Базовый | `Строка`, `Число(10)`, `Булево`, `Дата` | [Базовые типы](#Базовые%20типы) |
| Объект | `Ссылка."Заказ"` | Документ объекта |
| Перечисление | `Ссылка."СтатусЗаказа"` | Раздел «Типы и перечисления» документа объекта ([Определение типа](#Определение%20типа)) |
| Вложенный | `Ссылка."ПозицияЗаказа"` | Раздел «Типы и перечисления» документа объекта-хозяина ([Определение типа](#Определение%20типа)) |
| Список | `Список.ТипЭлемента`: `Список.Ссылка."ПозицияЗаказа"` | Тип элемента — по своему виду |
| Необязательный | Суффикс `?` у любого типа: `Дата?`; у ссылки — внутри текста ссылки: `[Ссылка."Покупатель"?](Покупатель.md)` | Без `?` значение обязательно |
| Со значением по умолчанию | После типа — `= значение`: `Ссылка."СтатусЗаказа" = Новый` | Значение из языка выражений ([Методы: Язык выражений](04-Методы.md#Язык%20выражений)) |

| Правило | Как выполнять | Тест |
|---|---|---|
| ВидТипа | Тип реквизита записан одним из видов таблицы выше; базовый тип — только из таблицы [Базовые типы](#Базовые%20типы). `Число` без размерности — ошибка; `Структура` — ошибка, состав задаётся вложенным типом ([Определение типа](#Определение%20типа)) | `test_типы` |

## Базовые типы

| Тип | Смысл |
|---|---|
| `Строка`, `Строка(Длина)` | Текст; без длины — неограниченный |
| `Число(Длина,Точность)` | Число: Длина — всего цифр, Точность — цифр после запятой, нулевую можно не писать. `Число(10)` — целое до 10 цифр, `Число(15,2)` — сумма с копейками |
| `Число(Длина,Точность,Неотрицательное)` | То же, только не меньше нуля |
| Булево | Истина или ложь |
| Дата | Дата и время |

## Реквизиты

\# Пример объекта «Заказ»:

| Имя | Описание | Тип |
|---|---|---|
| Покупатель | Кто оформил заказ | [Ссылка."Покупатель"](Покупатель.md) |
| Статус | Стадия заказа | [Ссылка."СтатусЗаказа"](#СтатусЗаказа) = Новый |
| Сумма | Сумма к оплате в рублях | Число(15,2,Неотрицательное) |
| ДатаОплаты | Когда заказ оплачен; пусто до оплаты | Дата? |

| [Тест](#Реквизиты) |
|---|
| `test_реквизиты_заказа` |

| Правило | Как выполнять | Тест |
|---|---|---|
| ФорматРеквизитов | Ровно три колонки: `Имя`, `Описание`, `Тип`; ссылки — только в колонке `Тип` | `test_формат_реквизитов` |
| СсылкаНаТип | Ссылка в колонке `Тип` ведёт на документ объекта, на заголовок перечисления или на заголовок вложенного типа этого же документа | `test_ссылки` |
| Инвариант | Постоянное условие на реквизиты — строка таблицы правил под таблицей реквизитов. Её тест проверяет условие после каждого метода объекта | `test_вид_таблицы` |
| ТестРеквизитов | Тест под таблицей реквизитов проверяет, что объект хранит ровно эти реквизиты, с их типами и обязательностью | `test_нет_отметки` |

## Определение типа

\# Перечисление и вложенный тип определяются в разделе «Типы и перечисления» документа объекта.

| Правило | Как выполнять | Тест |
|---|---|---|
| ОдноОпределение | Каждый тип определён в одном документе: заголовок определения типа уникален во всей спецификации, остальные документы ссылаются на него. Данные, которые уже описаны в другом объекте, подключаются ссылкой на этот объект, а не копией части его реквизитов; парсер проверяет только совпадение имён | `test_одно_определение` |
| СвойДокумент | Свой документ — у того, что используется без хозяина: его показывают, ищут или считают отдельно. Часть, которая без хозяина смысла не имеет, — вложенный тип в документе хозяина, даже если хранится в своей таблице. На вложенный тип ссылается только документ хозяина | `test_одно_определение` |
| Заголовок | Заголовок раздела — имя типа, затем комментарий с назначением | `test_определение_типа` |
| Перечисление | Таблица `Имя`, `Описание`, за ними при необходимости колонки свойств значения. В заголовке колонки свойства — имя и тип, как в колонке `Тип` реквизитов: `Баллы: Число(3)`; значения колонки подходят под этот тип. Свойство с именем `Тип` запрещено | `test_определение_типа` |
| Вложенный | Таблица в формате раздела [Реквизиты](#Реквизиты) | `test_определение_типа` |
| ТестПеречисления | Тест под таблицей перечисления проверяет, что в коде ровно эти значения, в том же порядке и с теми же колонками | `test_нет_отметки` |

### СтатусЗаказа

\# Пример перечисления: стадии заказа.

| Имя | Описание |

| Отменён | Заказ отменён до оплаты |

| [Тест](#Определение%20типа) |
|---|
| `test_статусы_заказа` |
