# Пример: спецификация → код → сгенерированные тесты

Выдуманный объект «Задача» и внешняя служба «Почта». Всё, что здесь лежит, прогоняется командами ниже.

| Что | Где | Кто написал |
|---|---|---|
| Спецификации | [спеки/Задача.md](спеки/Задача.md), [спеки/Почта.md](спеки/Почта.md) | Владелец с ИИ |
| Код | [код/задача.py](код/задача.py), [код/почта.py](код/почта.py), [код/часы.py](код/часы.py) | ИИ по спецификации |
| Привязка | [tests/привязка.py](tests/привязка.py) | ИИ, один раз |
| Тесты | [tests/test_по_спецификации.py](tests/test_по_спецификации.py) | Генератор |

## Запуск

Из корня репозитория:

```bash
python -m генератор пример/спеки пример/tests/test_по_спецификации.py
cd пример && python -m unittest discover -s tests -t .
```

## Что показывает пример

| В спецификации | Что порождается |
|---|---|
| Таблица реквизитов с значениями по умолчанию | `test_Задача_Реквизиты`: объект создаётся и читается без потерь |
| Перечисление `СтатусЗадачи` | `test_Задача_СтатусЗадачи`: те же значения в том же порядке |
| `Закрыть()`, две строки | Отказ «Задача уже закрыта» для закрытой; закрытие с подменённым `Сейчас` для открытой |
| `Выполнить()`, шаги с условием и `Откат` | Прогон со всеми шагами и письмом; прогон без уведомления; сбой на шаге 2 возвращает задачу в исходное состояние |
| `Факториал(N)` с рекурсией в итоге | База `0 → 1`, шаг `1 → 1` и пример `5 → 120` из таблицы `Примеры` |
| Инвариант «дата закрытия только у закрытой» | Генерация падает, если какое-то правило его нарушает |
| Внешний объект «Почта» | Проверяется, что `Отправить` вызван ровно с адресом и текстом из спецификации |

## Что ловится

| Если | Результат |
|---|---|
| В коде забыли `ДатаЗакрытия := Сейчас` | Падают три теста: закрытие и оба прогона `Выполнить` |
| В коде нет отката при сбое письма | Падает `test_Задача_Выполнить_СбойНаШаге2` |
| В спецификации изменили текст письма, код не тронули | Падает `test_Задача_Выполнить_ВсеШаги`: ожидался новый текст |
| В условие вписали вызов метода | Генерация падает: «вызовы допустимы только в эффектах и итогах» |
| Рекурсия без базы | Генерация падает: «правило не завершается» |
| Правило нарушает инвариант | Генерация падает с именем правила и инварианта |
